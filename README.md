# Resume Project Experience

一个用于核验并撰写中文简历项目经历的 Codex Skill。

它会读取代码、项目文档、截图、备忘录和用户陈述，核查项目的真实完成状态，并将材料整理成简洁、可信、能够在面试中继续解释的项目经历。

默认输出结构包括项目背景、内容描述和项目成果。

## 主要能力

- 区分已实现、已验证、规划中和无法确认的信息
- 核查项目功能、个人职责和量化数据是否一致
- 防止把自动化测试数量写成模型准确率
- 防止把普通内容库误写成 RAG
- 防止把单次模型调用误写成 Agent
- 避免夸大主导、上线、落地和业务提升等表述
- 使用能力小标题组织核心职责
- 优先生成可以直接放入简历的中文成稿

项目背景

## 安装方式

将仓库克隆到 Codex 的个人 Skills 目录。

```bash
git clone https://github.com/khu016/resume-project-experience.git ~/.codex/skills/resume-project-experience
```

也可以在 Codex 中使用 Skill Installer，通过以下 GitHub 仓库地址安装。

```text
https://github.com/khu016/resume-project-experience
```

## 使用方式

显式调用 Skill。

```text
使用 $resume-project-experience，根据我提供的代码和项目材料，撰写一段面向 AI 产品经理岗位的项目经历。
```

也可以直接提出需求。

```text
请核查这个项目的实际完成状态，并按照项目背景、内容描述和项目成果的结构写进简历。
```

## 使用示例

```text
使用 $resume-project-experience 帮我整理这个项目。

目标岗位为 AI 产品经理。
请先核查项目文件，不要把规划功能写成已经完成。
没有真实业务数据时，保留待补位置，不要编造提升比例。
```

## 事实核验原则

Skill 会优先参考以下材料。

1. 实际代码与可运行产物
2. 测试、评测和验收记录
3. 已确认的项目状态文档
4. 用户明确提供的个人职责
5. PRD、路线图与待办计划
6. 参考简历和示例图片

参考简历和示例图片只用于学习格式，不能证明用户实际完成过其中的工作。

## 文件说明

- `SKILL.md` 包含事实核验、项目分类、写作结构和交付检查规则
- `agents/openai.yaml` 包含 Skill 的展示名称、简介和默认调用语

## 适用范围

适合以下任务。

- 从代码仓库提炼项目经历
- 根据 PRD 和项目记录撰写简历
- 修改已有项目经历
- 检查项目成果是否夸大
- 区分 AIGC、RAG、Agent 和普通软件项目
- 将技术实现转换成产品经理简历语言

本 Skill 不会虚构项目成果，也不会替用户补写没有发生过的个人经历。
